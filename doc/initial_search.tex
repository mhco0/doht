\section*{Notes for My Paper}

- Jihyuk Lim and Kunsoo Park. Algorithm Engineering for All-Pairs Suffix-Prefix Matching:
    Algoritmo para "match" com sufixos e prefixos em sequencia de DNA. Os autores propoem uma estrutura de dados alternativa
    para o algoritmo de match em todos os pares de prefixo e sufixo. 
- Miki Hermann How to Find the Exit from a 3-Dimensional Maze
    Comparativo de algoritmos para o problema de encontrar um menor caminho dentro de um labirinto 3d
- Niklas Baumstark, Simon Gog, Tobias Heuer and Julian Labeit. Practical Range Minimum Queries Revisited
    Comparação do uso de uma Sparse table para se resolver o problema do RMQ
- Mateusz Basiak, Marcin Bienkowski and Agnieszka Tatarczuk. An Improved Deterministic Algorithm for the Online Min-Sum Set Cover Problem
    Algoritmo deterministico para o problema Min-Sum set cover com improviment no bound em tempo e espaço
- Philip Bille, Inge Li Gørtz, Simon J. Puglisi, and Simon R. Tarnow. Hierarchical Relative Lempel-Ziv Compression.
    Alternativa para a compressão Lempel-Ziv usando grafo esparso na construção.


Tambem achei essa conferencia $->$ European Symposium on Algorithms (ESA) 
- Loïc Dubois. Making Multicurves Cross Minimally on Surfaces 
   Parece interessante, mas dificil, tem haver com auto inserções de curvas em uma superficie mas com deformação na topologia do objeto.
- Yuhang Bai, Kristóf Bérczi, Gergely Csáji and Tamás Schwarcz. Approximating maximum-size properly colored forests
   Alternativa ao problema do Properly Colored Spanning Tree usando uma aproximação no modelo da árvore
*- Zhiyi Huang, Zahra Parsaeian and Zixuan Zhu. Laminar Matroid Secretary: Greedy Strikes Back
   Algoritmo guloso para atacar o Matroid Secretary Problem (ou problema da melhor escolha), parece ser um problema bem fechado com a solução especifica e otimizada para o problema.
   O paper parece curto e o codigo simples de ser implementado
*- Kou Hamada, Sankardeep Chakraborty, Seungbum Jo, Takuto Koriyama, Kunihiko Sadakane and Srinivasa Rao Satti. A Simple Representation of Tree Covering Utilizing Balanced Parentheses and Efficient Implementation of Average-Case Optimal RMQs
   Otimização da representação de árvores através de parenteses, com o objetivo de reduzir a memoria na representação da árvore em problemas de acesso e consulta, como por exemplo o RMQ.
